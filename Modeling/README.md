
# My Day Planner
## Web-Based Visual Schedule, Task Management and Communication System

### Project Description

My Day Planner is a web-based application designed to help caregivers, occupational therapists, and SPED teachers manage daily activities and routines for children with developmental delays.

### Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Python Flask
- SQLite
- Chart.js

### Features

1. User Registration and Login
2. Child Profile Management
3. Visual Schedule Creator
4. Drag-and-Drop Activities
5. Child-Friendly Interface
6. Task Completion Tracking
7. Visual Countdown Timer
8. Communication Board
9. Text-to-Speech
10. Progress Dashboard
11. CSV Report Export
12. Accessibility Settings

### Installation

1. Install Python 3.
2. Open the project folder in VS Code.
3. Create a virtual environment.
4. Install dependencies.
5. Run the Flask application.
6. Open the application in your browser.

### Run Command

python app.py

### Local URL

http://127.0.0.1:5000

### Database

SQLite database: visual_schedule.db

The database is automatically initialized when the application starts.

### Deployment Plan

Backend:
Render will be used to host the Flask application.

Database:
SQLite will be used for local development. A persistent hosted database should be configured for production deployment.

Frontend:
The frontend will be served through Flask.

Security:
Environment variables will store production configuration and secret keys. HTTPS will be used for deployed access.
